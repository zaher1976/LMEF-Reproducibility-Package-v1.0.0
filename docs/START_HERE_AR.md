# دليل تشغيل LMEF

المشروع يدرس كشف أعطال الألواح الشمسية من الصور، ويضم تحليلاً لقياسات حرارية وكهربائية مقترنة. توجد ثلاثة مسارات مستقلة، ولا توجد حالياً واجهة تطبيق أو نموذج مدرب جاهز للتنبؤ بصورة جديدة.

| بياناتك | البداية | النتيجة |
|---|---|---|
| صور PVF-10 ذات تقسيم train وtest | `PVF10_Final_Training.ipynb` | مقاييس اختبار CNN ومصفوفة الالتباس |
| صور مصنفة داخل مجلد لكل فئة | `PV_Thermal_Fault_Detection_Training.ipynb` | تدريب CNN عام بتقسيم داخلي 70%/15%/15% |
| ملفات CSV حرارية وMAT كهربائية | `mendeley_physical_validation.py` | خصائص حرارية وكهربائية، دون تصنيف |

## تدريب الصور

1. افتح رابط Colab المناسب من [الصفحة الرئيسية](../README.md)، واحفظ نسخة في Drive.
2. شغّل الخلايا بالترتيب واقرأ الشرح قبل كل مرحلة. GPU اختياري.
3. في PVF-10، عدّل `ROOT` إلى مسار بياناتك بعد ربط Drive. يجب أن يحتوي المجلد على `train` و`test`، وداخل كل منهما مجلدات الفئات وصورها مباشرة.
4. في المسار العام، ارفع ZIP يحتوي مجلدات الفئات مباشرة في جذره. إذا وُجد مجلد يحيط بكل الفئات، عدّل `DATA_ROOT` بعد الاستخراج.
5. راجع أسماء الفئات وأعداد الصور وأحجام التقسيمات قبل التدريب. المسار العام يستبعد الصور غير القابلة للقراءة والصور التي حجمها لا يتجاوز 20,000 بايت؛ هذا الشرط لا يثبت جودة الصورة.
6. نزّل JSON النتائج وصورة مصفوفة الالتباس من الخلية الأخيرة. احفظ كل تشغيل في مجلد مستقل.

ملفا Python الخاصان بالتدريب مستخرجان من الدفاتر ويعتمدان على Colab؛ لا تبدأ بتشغيلهما محلياً بأمر `python`.

## افحص المدخلات أولاً

من مجلد المشروع، نفّذ الأمر المناسب بعد استبدال المسار:

```bash
python check_inputs.py pvf10 --root /path/to/PVF_10_Ori
python check_inputs.py thermal --root /path/to/class_folders
python check_inputs.py mendeley --root /path/to/paired_files
```

هذه الأداة تفحص ترتيب الملفات فقط، ولا تتحقق من محتوى الصور أو القياسات، ولا تنفذ تدريباً. يمكن فحص نسخة البيانات محلياً أو نسخ الأداة إلى Colab واستخدام المسار هناك.

## فهم المخرجات

- `test_accuracy`: نسبة التصنيف الصحيح بين 0 و1.
- `macro_precision` و`macro_recall` و`macro_f1`: متوسط غير موزون بين الفئات. لتحويل القيم إلى نسب مئوية اضربها في 100.
- `confusion_matrix`: الصف للحقيقة والعمود للتنبؤ، بترتيب قائمة `classes`.
- `latency_ms_*`: زمن تمرير الشبكة لصورة واحدة بعد الإحماء، دون تحميل الصورة ومعالجتها. حقول GPU تكون فارغة عند تشغيل CPU.
- ملف Mendeley يصف الحرارة ومنحنى التيار والجهد. `Isc_est_A` و`Voc_est_V` تقديرات بالاستقراء وليستا قياسات مباشرة لنقطتي النهاية.

الحزمة لا تتضمن البيانات أو الأوزان المدربة أو النتائج الأصلية، وبعض تجارب المخطوطة غير مرفقة. راجع [خريطة التغطية](../MANUSCRIPT_CODE_MAP.md) و[تفاصيل المسارات](WORKFLOWS.md). توثيق مصدر البيانات وإصدارها وترخيصها ضروري لمقارنة أي تشغيل بأرقام الورقة.
